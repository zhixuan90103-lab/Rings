# 基础件

当前画面是零件表，不是关卡。规则仍在 [ROTATE-RINGS.md](./ROTATE-RINGS.md)。`npm run dev` 画的是这里的拼法。

顶视，正交相机从 +Z 看 XY。零件是有厚度的扁片。背景 `#fbf0e0`。

代码在 `src/game/parts.ts`。`play.ts` 的 `showSpecimens` 只负责摆放。

## 单独部件

一件只做一种形状。颜色、个数、装在谁身上，由组合决定。

| 部件 | 外形 | 尺寸 |
|---|---|---|
| 圆环 | 开口环带。切口圆头。外圈、内圈、切口都倒角 | 外半径 `0.72`，环带是外半径的 28%，缺口 `1.75`，厚 `0.18`，再整体缩到 90% |
| 竖杆 | 直条。上下两端直角，左右长边倒角 | 长是环带的 `2.5 × 2/3`，宽是环带的 88%，厚与环相同 |
| 横柄 | 直条。左右两端直角，上下长边倒角 | 长是环带的 `2.1 × 5/6`，宽是环带的 140% |
| 胶囊棍 | 两端圆头的长条，棱上倒角 | 长是圆环外径的 1.5 倍，宽等于缩放过的环带 |
| 银卡扣 | 左右直切，上下倒角。上下各一块长方形把手 | 宽是棍的 130%。长度按未加长的棍算，是该长度的 `0.32 × 2/3`。把手再缩到 70%。颜色 `#c8c7c5` |

圆环和胶囊棍用场景里的真实投影，光从上方略偏左，影子落在右下，贴着物体。银卡扣不投影，自己贴一块更近的软阴影，方向同样偏右下。

## 组合

**环上衔接**是一根竖杆加一根横柄。接到圆环外侧的任意角度，一只环可以接多套。颜色跟这只环。

从近到远：横柄、圆环、竖杆。竖杆在环下面，横柄压在竖杆上面。

**带卡扣的胶囊棍**是一根胶囊棍加一枚银卡扣。卡扣在棍的中点。棍加长时，卡扣不跟着变长。

## 当前摆放

- 蓝环，没有衔接。缺口朝上。
- 绿环，开口对面的外侧一套衔接。缺口朝上。
- 红胶囊棍，中段一枚银卡扣。

再加一套衔接，给 `ringWithConnectors` 再传一个角度。不要把竖杆写进圆环网格里。
