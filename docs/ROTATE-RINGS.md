# Rotate Rings · 方法规范

日期：2026-10-26  
来源表：[ROTATE-RINGS-SOURCES.md](./ROTATE-RINGS-SOURCES.md)  
范围：开口环、闭合环、长条滑杆。不含松果、道具。

## 1. 规则

拖动只改角度或杆的位置。实心顶到销、限位或未解开的卡扣时，这一向停住。缺口在拖动中盖住关节，零件仍留在盘上。

`pointerup` 才结算。当时被缺口盖住的阻挡销或关节删掉；杆落在松开窗口里，对应卡扣解除。`pointercancel` 恢复这次拖动开始时的角度或位置，不删连接。

可删连接数为 0 的零件离场。离场不是原地消失：从规则控制改成受重力的物体，物理掉落，掉出画面后再删。连锁只在这次抬手结算之后发生。掉落物不能推动仍被规则按住的零件，也不能重新套上销钉上锁。

过关是盘面上的规则零件全部离场。一次只拖一个物体。互锁来自关卡里写好的销、卡扣，以及仍在盘上的环挡住导轨。不来自刚体接触。

画面和规则是同一件事。银箍必须落在杆和环真正卡住的地方。不能出现规则上互锁、画面上分开，或画面上套在一起、规则上各走各的。

关卡要有拆解先后。后一根杆的导轨被前面还在盘上的环挡住。只把后一根杆自己的开口转开不够，要等前面的零件离场。

## 2. 连接与障碍

| 种类 | 拖动 | 抬手 | 是否把零件留在盘上 |
|------|------|------|--------------------|
| 阻挡销、关节 | 实心段顶住就停 | 缺口盖住则删这条连接 | 是。可删连接为 0 才离场 |
| 限位销 | `stopHalf > 0` 时顶住 | 不删 | 否。只限制角度，所属零件离场时带走它 |
| 银箍标记 | 不挡 | 不删 | 否。`stopHalf = 0` 的限位销，只标出杆和环的交叉，跟着所属的杆离场 |
| 卡扣 | 卡扣点落在环带内才收紧转角。落在环心只把环留在盘上 | 不看环的缺口。杆进入窗口才解除 | 是 |
| 闭合环 | 没有缺口，自己的抬手不删连接 | 只靠别的零件离场后的连锁 | 是，直到连接为 0 |

## 3. 主方法

写好的关节加一维区间。环的轴是绕自身圆心的角度 θ，杆的轴是沿导轨的位置 t。圆心和导轨在这次拖动里不动。

1. 每个写好的障碍在这根轴上占一段禁区。销钉用它相对圆心的角和实心张角得到两个端点。杆的两端是导轨的 0 和 1。导轨上的点若落在仍在盘上的环的实心段里，这一段 t 是禁区。环一转，开口盖住该点，这段禁区消失。未解开的卡扣只在它的点落在环带内时才收紧转角。
2. 禁区间按起点排序并合并。
3. 拖动目标夹在当前自由区间内。顶到端点就停，反向可退。
4. 抬手用跨过 0 的区间判断缺口是否盖住关节。杆用位置是否落在松开窗口里。
5. 删掉本次解除的连接。连接数为 0 的零件退出规则，交给物理掉落。再检查因此变成 0 的零件，同一轮一起掉。

跟手增量用 `atan2` 的有符号差，每次移动用这一帧的增量，不把被挡住的拖动累加成大角度。点选用射线，取最近的一个；没有命中再用环带或杆身的几何距离。手指滑出元素仍要收到移动，用指针捕获。

桌面预览会再缩放外层视口。指针先用画布的 `getBoundingClientRect` 换到设计坐标 390×844，再换到正交视口。不要只用 letterbox 的 `offsetX` / `offsetY`。

## 4. 辅助

主方法算不出禁区端点时才加辅助。夹紧和抬手结算不变。

| 情况 | 辅助 | 交回主方法的结果 |
|------|------|------------------|
| 销、卡扣、直杆 | 不需要 | — |
| 三角框、U 型管等不再是一个点的轮廓 | 临界角：绕定点把顶点与边求交，排序 | 禁区端点 |
| 个别形状临界角不划算 | 沿这根轴二分，找第一下接触 | 同一个端点 |

## 5. 不用

离散档位不作唯一模型。先转到目标再查重叠、动态合页、用接触生成互锁，都会改掉跟手或抬手时机。`DragControls` 的旋转绕相机轴，不绕环心。分离轴只回答是否重叠，不回答这根轴还能走多远。

物理引擎只在零件已经退出规则之后做掉落。还在规则里的零件不用动力学关节保持互锁。

## 6. 画面

规则在 XY 平面。正交相机从 +Z 看向原点，上方向是 +Y。角度 0 在 +X，逆时针。`mesh.rotation.z` 用同一个 θ。

当前画出来的是零件表，不是这一节下面的关卡。零件外形、组合和当前拖动见 [PARTS.md](./PARTS.md)。环绕自己的中心转，红胶囊棍水平滑动，银卡扣锁在画面上。关卡网格先不画，松手也不结算离场。

掉落仍是解开之后的重力。还在规则里的零件不使用动力学关节。

## 7. 当前原型

关卡 `levelScreen`（`src/game/levels.ts`），名字「从上往下拆」。三环三杆，只能按这个顺序：

1. 蓝环挡住红杆。把蓝环开口转到银箍上，红杆才能滑出。松手后红杆和蓝环一起离场。
2. 蓝环还在时，橙杆过不去。蓝环离场后，把绿环开口转到银箍上，再抽出橙杆，绿环一起离场。
3. 绿环离场前紫杆过不去。之后把橙环开口转到杆上，抽出紫杆，橙环一起离场。

只转动圆环不会离场。卡扣写在环心，不在环带上，所以它把环留在盘上，但不把转动收成缺口那么窄。银箍是 `stopHalf = 0` 的限位销，坐标钉在杆上。
