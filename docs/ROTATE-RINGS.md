# Rotate Rings · 方法规范

日期：2026-10-28  
来源表：[ROTATE-RINGS-SOURCES.md](./ROTATE-RINGS-SOURCES.md)  
范围：开口环、闭合环、长条滑杆。不含松果、道具。

## 1. 规则

拖动只改角度或杆的位置。实心顶到销、限位或未解开的卡扣时，这一向停住。缺口在拖动中盖住关节，零件仍留在盘上。

`pointerup` 才结算。世界销被缺口盖住就删。别人的把手要同时满足两件才删：缺口盖住它，并且柄已经离开这只环的实心。套筒卡扣在整根杆身离开后解除。窗口卡扣在杆的 t 落入 `[t0, t1]` 时解除。`pointercancel` 恢复这次拖动开始时的角度或位置，不删连接。

离场看的是「谁还被留在盘上」，不是任意连接归零。长条只被限制自己的卡扣留住：杆从这只卡扣里摘出来，抬手后长条掉落，不带走环。环和环还彼此连着时，两边都留在盘上。抬手解开这只连接之后，不再连着别的环的那些环才掉落。离场不是原地消失：抬手结算后按 §7 碎成圆角方块再离开画面。连锁只在这次抬手结算之后发生。碎块不能推动仍被规则按住的零件，也不能重新套上销钉上锁。

过关是盘面上的规则零件全部离场。一次只拖一个物体。

谁挡住谁：

- 圆环的环身和缺口不挡住另一个圆环。两个环靠在一起、缺口套着对方，都不算牵制。
- 圆环要牵制另一个圆环，只用环上的竖条和把手。被卡住的那只环拖动时可以转进转出，把手不挡它。抬手要同时满足两件才解开：缺口对准这只把手，并且柄已经不在这只环的实心里。只对准缺口、柄还嵌着，两边都还留着。
- 长着这只卡扣的环，在卡扣还嵌在对方实心里时不能转。卡扣转出去会挤到对方环身。对方缺口转到卡扣上之后，卡扣才能从缺口转出来。
- 红色长条占着圆环缺口时，环仍能转，直到实心碰到杆或银卡扣才停，不会被整段角度锁死。杆没有轨道端点，沿自己的长边一直滑。胶囊和环的实心、或和另一根杆的胶囊，从分开变成碰上或埋得更深，这一向才停；把重叠抽小不受影响。长条不靠「离开缺口」来放开环。环留不留在盘上，只看环和环的连接。

银卡扣挡住环的实心。它不留环，也不挡住自己的杆。

画面和规则是同一件事。圆环、胶囊棍、银卡扣的碰撞轮廓跟画出来的形状一致：画面重叠就挡住，画面之间有空隙就不算碰到。银卡扣套在棍上，棍可以穿过自己的卡扣。圆弧柄用来把另一只环嵌住：被嵌的环可以在柄里转，长着这只柄的环在还嵌着时不能把柄转出来。银卡扣钉在自己的固定点，不跟杆滑。

关卡要有拆解先后。后一根杆的导轨被前面还在盘上的环挡住。只把后一根杆自己的开口转开不够，要等前面的零件离场。

## 2. 卡扣属于谁

每只卡扣只有一个主人。再加长条或圆环时，按主人挂上去，不写一对「又像环又像杆」的编号。

| 卡扣 | 主人 | 留住谁 | 怎么解开 |
|------|------|--------|----------|
| 银卡扣 | 一根长条 | 只留这根长条 | 套筒：整根杆身离开固定点后，抬手这根长条才掉，卡扣从该点一起掉。杆心过了卡扣、杆身还穿着时不掉。窗口：t 落入 `[t0, t1]` 才解除 |
| 把手 | 一只圆环 | 主人，以及把手正嵌住的那只环 | 被嵌的环抬手时，缺口对准这只把手，并且柄已经离开实心 |
| 世界阻挡销 | 盘面 | 销还落在其实心里的那只环 | 这只环抬手时缺口盖住销。`block` 会挡住转动，`catch` 只留住环 |

环和环还通过把手连着时，两边都留在盘上。留人看画出的柄是否还碰上另一只环，不看销钉点有没有落在孔心外面。长条的银卡扣不参与这只连接。

## 3. 连接与障碍

| 种类 | 拖动 | 抬手 | 是否把零件留在盘上 |
|------|------|------|--------------------|
| 阻挡销 | 实心段顶住就停 | 缺口盖住则删这条连接 | 是。可删连接为 0 才离场 |
| 卡扣里的环 | 不挡这只环。它可以转进转出 | 抬手时缺口对准，并且柄已离开实心，才解开 | 是。环和环还连着时两边都留着 |
| 长着卡扣的环 | 卡扣还嵌在对方实心里时转不动。对方缺口对准后，卡扣才能转出 | 不靠自己的缺口解开 | 是。这只连接同时留住两边。解开后，不再连着别的环才掉落 |
| 限位销 | `stopHalf > 0` 时顶住 | 不删 | 否。只限制角度，所属零件离场时带走它 |
| 银卡扣形体 | 挡住环。重叠变深就停，抽小放行。不挡自己的杆 | 不删这只连接 | 否。套筒卡扣的固定点在 `Latch` 上，主人离场时带走 |
| 长条自己的卡扣 | 不把环留在盘上。形体仍挡住环 | 套筒看杆身是否还穿过；窗口看 t 是否落入 `[t0, t1]` | 只留住这根长条。摘出来后长条掉落，环还彼此连着就留在盘上 |
| 闭合环 | 没有缺口，自己的抬手不删连接 | 只靠别的零件离场后的连锁 | 是，直到连接为 0 |

## 4. 主方法

环的轴是绕自身圆心的角度 θ，杆的轴是沿自己长边的位置 t。圆心和长边方向在这次拖动里不动。按住杆上的哪一点，杆就跟着这一点沿长边移动，不是把杆心拉到手指下面。

体积关（`volumes`）按画出来的形体走，不用轨道端点：

阻挡只用一条判定，环和杆共用：这一步让一对零件从分开变成碰上，或让已有重叠更深，就退回上一步。把重叠抽小的一步放行。

1. 环的重叠是三样：自己的衔接已经嵌在另一只环的实心里时，往哪边转都停；衔接这一步才嵌进去，也停。再加上整根杆的胶囊、以及这根杆的银卡扣，和这只环的实心。环带不挡另一只环的环带。银卡扣不挡自己的杆。
2. 杆的重叠是两样：胶囊和任一环的实心（环带、缺口圆角、这只环的衔接），以及胶囊和另一根杆的胶囊。银卡扣不在这里。
3. 被挡住的那一下给碰撞反馈，环和环、环和杆、杆和杆相同。正在拖的那一件发亮。这一下已经带动过零件时，接触点溅出粒子。零件这一下完全没带动，只发亮并走无效晃动，不溅粒子。同一次顶住不重复。
4. 抬手才结算。体积关里，别人的把手要同时满足两件才解开：缺口盖住这只把手，并且柄已经不在这只环的实心里。世界销仍只看缺口。杆的银卡扣看整根杆身是否还穿过；旧关卡的窗口卡扣才用松开窗口。
5. 银卡扣没了，这根长条离场，不带走环。银卡扣从锁住的位置一起碎开，不留在画面上消失。环不再连着别的环、也没有世界销留住时，这些环同一轮离场。离场的样子见 §7。

销钉关不采样体积。环走阻挡销和限位销的禁区弧，杆的 t 夹在 0 和 1 之间。这些关卡的卡扣用窗口，不用套筒。体积关不把采样折回禁区弧。

跟手只吃这一帧手指滑过的位移，被挡住的那截丢掉，不累加，松手后也不追手指。

圆环按切向弧长转。上一帧手指相对圆心是 `r`，这一帧位移是 `dp`，杠杆是 `max(|r|, 环带半径)`：`dθ = (rx·dpy − ry·dpx) / 杠杆²`。滑进孔里不会被放大，径向滑动不转。一帧里的直线按环带半径拆成小段再累加，不用 `atan2` 的最短角差。

长条只加手指沿长边的位移。挡住就停在接触前的那一步。

### 意图

意图在指针和 `dragTo` 之间，代码在 `src/game/intent.ts`。它决定拖谁、沿哪条轴。角度、`t`、重叠退回和抬手删连接仍走上面的公式。三个比例都相对设计短边 390，再按当前镜头缩放换到世界，不写成固定的 `t`。

| 比例 | 常量 | 作用 |
|------|------|------|
| 10% | `INTENT_PAD` | 环心，以及环带、杆身外侧的放大命中 |
| 2% | `INTENT_WINDOW` | 按下后用来确认转环还是滑杆的位移 |
| 6% | `INTENT_SLEEVE` | 抬手时套筒离「刚离开」还允许补上的距离 |

基础命中是射线打中的环或杆，或几何上落在环带、杆身里的点。放大命中是环心和外侧 10%。放大只加给这一向还能动的零件：杆只有一边能走，就只有这一边算数。两边都顶死的零件没有放大命中。基础命中即使这一向已经顶死也保留，走无效晃动。银卡扣不产生意图。

按下只列候选，不改姿态，并记下采样。之后：

1. 沿轴分量大于横向分量的 1.5 倍，并且明显大于另一个候选时，立刻锁定这一件。
2. 否则等到位移累计满设计短边的 2%。仍接近两个轴的中间，就用按下时分数最近的一件。环的分数是到环带中线的距离，孔心最远。杆的分数是到杆心线的距离。
3. 没有任何还能响应这个方向的候选，这一笔结束，不开始拖动。

锁定后，把按下以来的采样按原顺序交给 `dragTo`，只留锁定轴上的分量。这 2% 用来分类，不另加一段位移。确认后不再换件。

抬手、并且这一笔沿杆的方向没有换过时，若卡扣是套筒，并且沿长边离「刚离开」不超过设计短边的 6%，就把这段换成世界长度交给 `moveBar`。重叠变深仍停在接触前。窗口卡扣不补。离套筒还远于这 6% 时，速度不补。

按下只收设计画面内的点。拖动中用指针捕获，滑出画面仍跟踪。一次 `pointermove` 里若有合并采样，中间点只用来看长边方向有没有换，跟手仍取最后一点。`dragTo` 再把从上一点到这一点的直线按环带半径拆开。`pointercancel` 回到这一笔开始时的角度或 `t`，套筒补齐一并撤销。

桌面预览会再缩放外层视口。指针先用画布的 `getBoundingClientRect` 换到设计坐标 390×844，再换到正交视口。不要只用 letterbox 的 `offsetX` / `offsetY`。

## 5. 辅助

体积关和现在的销钉关都不走这一节。主方法算不出禁区端点时才加辅助。夹紧和抬手结算不变。

| 情况 | 辅助 | 交回主方法的结果 |
|------|------|------------------|
| 销、卡扣、直杆 | 不需要 | — |
| 三角框、U 型管等不再是一个点的轮廓 | 临界角：绕定点把顶点与边求交，排序 | 禁区端点 |
| 个别形状临界角不划算 | 沿这根轴二分，找第一下接触 | 同一个端点 |

## 6. 不用

离散档位不作唯一模型。先转到目标再查重叠、动态合页、用接触生成互锁，都会改掉跟手或抬手时机。`DragControls` 的旋转绕相机轴，不绕环心。分离轴只回答是否重叠，不回答这根轴还能走多远。

离场不用物理引擎，也不给还在规则里的零件加动力学关节。退出规则之后才按 §7 碎裂。

## 7. 画面

规则在 XY 平面。正交相机从 +Z 看向 −Z，上方向是 +Y。角度 0 在 +X，逆时针。`mesh.rotation.z` 用同一个 θ。参考世界高度是 10，宽度按 390×844。缩放只改 `camera.zoom`，平移只改相机的 `x/y`。掉落用的世界底边不跟镜头变。

进关时把这一关放进标题和底栏之间，四周再留 24 个设计像素。外框按现在画出的环、柄和杆，不含柄转到其他角度时的空位。镜头在左右对准这块可用区域的中心，上下再抬 48 个设计像素；外框已经顶满高度时不再抬。缩到整关刚好落下。这是最远。放大上限按圆环在画面上的大小：不能超过第一关在这个最远镜头里的最大环。某关一进来已经更大，就不再放大。计算在 `camera.ts`。

试玩只用两指动镜头，不吃滚轮。一次双指只做一种：两指间距或中点先移动满 12 个设计像素，就锁定放大或平移，松手之前另一种不生效。放大绕当前两指中点，中点底下的点留在中点下。平移从锁定那一帧起，中点底下的点跟着中点走。边界在这次计算之后才夹：关卡比窗口大时窗口不滑出关卡，关卡比窗口小时关卡不滑出窗口。夹边界不改缩放。放大不超过第一关最远镜头里的最大环。第二指按下取消正在进行的零件拖动，环或杆退回按下时的姿态。手指数不是 2 就结束。还有手指按着时，不再开始零件拖动，直到全部抬起。

编辑模式不吃两指，也不吃滚轮。工具栏有两条滑杆。「镜头」中间是整关刚好落下，向左远 4 倍，向右近 4 倍。「上下」中间是原来的取景高度，向左看低一个画面，向右看高一个画面。两条都绕可用区域的水平中心。编辑时不再把画面夹回关卡里。

最后一件规则零件开始掉落时计 1 秒，然后弹出结算。前面的零件先掉不计时。计时只在试玩里走。试玩松手不走进编辑器，避免同一次松手把这次过关清掉。结算层的样子见 §11。

试玩读 `public/levels/1.json`。外形见 [PARTS.md](./PARTS.md)。环按 §4 绕自己的中心转，杆沿长边滑动，银卡扣锁在画面上。松手按这一节结算。`levelBasic` 仍是手写参考，见 §8，不直接铺到画面上。

解开的那一帧，圆环、长条、以及这根长条的银卡扣，各自换成一堆圆角方块。原来的网格同时隐藏。实现和数字在 `src/game/shatter.ts` 的 `SHATTER`。

铺点跟松手时画出的外形一致，不铺整圈预留。环铺环带、缺口两端的圆盖、直杆和柄。长条铺胶囊。银卡扣铺套筒和卡爪，从锁住的位置碎，不跟杆滑。环带只有一层，间距 `step` 为 `0.16`。边长 `chip` 为 `0.1`，厚度 `depth` 为 `0.1`，倒角 `bevel` 为 `0.018`。每块再乘 `0.55` 到 `1.15`。环和杆用自己的 `color`，银卡扣用 `buckle`。方块画在仍锁着的零件前面（`FALL_Z`），不投阴影。

运动是一条弧，中间不改速度。每块相对这件中心的初速在 `0` 到 `1.6` 之间随机，方向向外，可以为 0。出现时已沿该方向走出最多 `0.16`，按初速比例。预先散开的平均位移和平均初速要减掉，整团中心仍在松手时的零件上。重力 `-30` 一开始约一半，再在 `0.12` 秒内加满。飞行中绕三轴翻滚。下落时在 `0.75` 秒内缩到 `0.45` 倍，不再缩成小点。掉出画面下沿后删除。方块之间、以及和还锁着的零件，都不碰撞。

生成时先走 `1/60` 秒。碎块网格和撞击圆片都放在对象池里，不在每次解锁或撞击时创建和销毁。颜色、初速、大小和寿命每次重写。

画面反馈只画在正在操作的那一只上，不写回规则角度或杆的位置。代码在 `src/game/feedback.ts`。

无效晃动的第一次幅度已定：圆环 3°，长条 3 个设计像素。来回 3 次，约 0.42 秒，后一次大约是前一次的六成。点击没有方向，直接播，幅度是按住的三分之二，零件还留在盘上才播。圆环这次还没带动规则姿态就被挡住时，按住停在第一次那一向上的 3°，继续拖不再采样，抬手后从这 3° 晃回规则角度。长条没有按住，挡住后立刻结束拖动并晃。已经带动过规则姿态的拖动继续跟手。

挡住时发亮。粒子只在这一下已经带动过零件时出现，见 §4。接触点取这一步新碰上的那一块，不把环两侧平均到环心。已经嵌死、这一步没有新采样点时，用当前接触点。9 颗圆片，颜色用正在拖的那一件自己的 `color`，没有存颜色才按名字取。不透明，初始直径是 0.055 的 70%，按寿命缩小，重力为 16。生成时先走 1/60 秒。圆环再转开约 0.08 弧度，或长条再滑过 0.03，下一次撞击才再亮。完全没带动的那一下不生成这些圆片。

背景色 `#f6f1e8`，场景和页面用同一个颜色。接影面透明，只承接还在规则里的零件的影子。碎块不往这层投。缺口端盖的碰撞圆和画出的半圆相同，半径是环宽的一半。

## 8. 当前原型

关卡 `levelBasic`（`src/game/levels.ts`），名字「三件」：

1. 开局蓝环卡在绿环把手里。蓝环可以自由转进转出。松手时缺口正对把手，并且柄已经离开蓝环实心，这只连接才解开。只对准缺口、柄还嵌着，两边都还留着。
2. 把手还嵌在蓝环实心里时，绿环转不动。蓝环缺口转到把手上之后，绿环才能把把手从缺口转出来。绿环自己的环身碰到红杆也会停。
3. 红杆斜着插在蓝环缺口里。杆从限制自己的卡扣里摘出来，松手后红杆掉落，银卡扣从锁住的位置一起掉。两环还连着，留在盘上。
4. 环和环的连接解开之后，不再连着别的环的蓝环和绿环一起掉落。两个环的环身不互相挡。

银卡扣在杆还穿着时锁在画面上，不跟着杆滑。杆身离开后，它和杆一起掉，不消失在原地。

关卡 `levelScreen`，名字「从上往下拆」。三环三杆，只能按这个顺序：

1. 红杆的银卡扣只属于红杆。抽出后松手，只有红杆掉落。蓝环由自己的世界销留住，缺口盖住这只销再松手，蓝环才掉。
2. 蓝环还在时，橙杆过不去。蓝环离场后，绿环开口转开，橙杆才能抽出。橙杆的卡扣只掉橙杆。绿环靠自己的销离场。
3. 绿环离场前紫杆过不去。橙环同样靠自己的销离场，紫杆靠自己的卡扣离场。

只转动圆环不会离场。衔接写在环的 `connectors` 里，空数组表示没有衔接。每一项是本地角、直杆长度、要嵌住的环。银卡扣是 `release: 'sleeve'` 的卡扣，固定点是它自己的 `x, y`，不是销。`stopHalf > 0` 的销才限制角度。`release: 'window'` 只留给销钉关。`levelScreen` 的三只卡扣是套筒，不读 `t0` / `t1`。

## 9. 关卡编辑

顶栏右侧齿轮是 **设置**。**关卡模式** 默认关。关掉时按试玩拖动，编辑工具不出现。打开后才进入编辑。试玩不在画面上写「第 N 关」；`#status` 只留下编辑提示，例如保存结果和颜色冲突。空的时候不占位。

编辑只在 `npm run dev` 里保存。关卡是 `public/levels/1.json` 到 `5.json`。`src/game/levels.ts` 仍是手写关，编辑不写这个文件。

| 能改 | 规则 |
|------|------|
| 每个环、每根杆的位置和角度 | 角度 0 是 +X，逆时针。数值在「属性」里，位置步进 `0.01`，角度步进 `0.1°` |
| 环的大小 | 弧形柄跟环带宽度一起缩放，比例不变 |
| 一只环上的多只柄 | 每只柄单独有角度、直杆长度、目标环。柄的颜色跟主人环 |
| 相连的两件 | 颜色必须不同 |
| 杆和银卡扣 | 编辑时一起挪，卡扣留在杆的中点。试玩时卡扣仍锁在画面上，不跟杆滑 |

点保存时，按这个顺序处理，然后写回当前关的 JSON：

1. 没选目标、但弧形柄已经套在某只环上的柄，绑上那只环。
2. 横坐标离画面中心至少 1 的环，按左右分成两列。两列用同一个距离，左列是负的，右列是正的。这个距离取这些环现在离中心的平均。中间的环保持摆好的位置。
3. 不挪环心去凑柄。每只柄改自己的角度和直杆长度，使弧形柄的圆心正好落在目标环心上，不再和环错位穿插。
4. 整关外框移到画面中心 `(0, 0)`。相对位置不变。

前 6 个新环用蓝、绿、红、橙、紫、黄。之后的新环在这些颜色附近随机偏 20° 到 44°，并躲开盘面上已有的色相。

## 11. 顶栏与夸奖

试玩顶栏在 `#ui-root` 里，不挡零件。左是「关卡」和关卡号，这一列内部居中，「关卡」15px，数字 18px。中是分数胶囊：底色 `#c4beb4`，4px 白色描边、透明度 60%，数字在描边内居中。右是齿轮，打开设置。画面底色 `#f6f1e8`。

每消掉一只环加 100 分。杆离场不加分。重玩或进入下一关时回到 0。

结算层是 `#result`，盖住整个 `#ui-root`，挡住后面的点击。文案是「恭喜过关」。下面两个按钮：

- **重玩**再开当前关。
- **下一关**进入后一关。第 5 关回到第 1 关。

编辑时不弹出。过关后不自动换关。

一次操作最多一句夸奖，出现在目标上方 56 设计像素。拖的那件自己离场，字在它上方；它还在，字在这次被消掉的那件上方。

阶从弱到强是 Great!、Perfect、Excellent!、Amazing。连击记在 `praise.ts`：

- 一连串里第一次只消掉一件，不显示。
- 第一次就消掉多件，直接显示 Perfect。
- 之后每次再消除，中间没有撞错，升一阶。一次消掉多件，升两阶。到 Amazing 为止。
- 拖动里出现 `hit` 或 `stop`，连击断开。下一次消除重新算第一次。
- 换关或换一盘，连击断开。

字从 0.8 放到 1.08，再用约 240 毫秒收回 1。同时用 500 毫秒升起约 28 像素，略向一侧，后段淡出。放大动画结束不能拆掉这句话，要等上升结束。
