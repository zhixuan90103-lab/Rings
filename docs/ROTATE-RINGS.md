# Rotate Rings · 方法规范

日期：2026-10-27  
来源表：[ROTATE-RINGS-SOURCES.md](./ROTATE-RINGS-SOURCES.md)  
范围：开口环、闭合环、长条滑杆。不含松果、道具。

## 1. 规则

拖动只改角度或杆的位置。实心顶到销、限位或未解开的卡扣时，这一向停住。缺口在拖动中盖住关节，零件仍留在盘上。

`pointerup` 才结算。当时被缺口盖住的阻挡销或关节删掉；杆落在松开窗口里，对应卡扣解除。`pointercancel` 恢复这次拖动开始时的角度或位置，不删连接。

离场看的是「谁还被留在盘上」，不是任意连接归零。长条只被限制自己的卡扣留住：杆从这只卡扣里摘出来，抬手后长条掉落，不带走环。环和环还彼此连着时，两边都留在盘上。抬手解开这只连接之后，不再连着别的环的那些环才掉落。离场不是原地消失：从规则控制改成受重力的物体，物理掉落，掉出画面后再删。连锁只在这次抬手结算之后发生。掉落物不能推动仍被规则按住的零件，也不能重新套上销钉上锁。

过关是盘面上的规则零件全部离场。一次只拖一个物体。

谁挡住谁：

- 圆环的环身和缺口不挡住另一个圆环。两个环靠在一起、缺口套着对方，都不算牵制。
- 圆环要牵制另一个圆环，只用环上的竖条和把手。默认环卡在这只卡扣里面。被卡住的那只环拖动时可以转进转出，卡扣不挡它。抬手那一刻才看缺口有没有对准卡扣：对准就解开，没对准就仍卡着。
- 长着这只卡扣的环，在卡扣还嵌在对方实心里时不能转。卡扣转出去会挤到对方环身。对方缺口转到卡扣上之后，卡扣才能从缺口转出来。
- 红色长条占着圆环缺口时，环仍能转，直到实心碰到杆才停，不会被整段角度锁死。杆没有轨道端点，沿自己的长边一直滑。只有正在推进去的那一端要进入实心时，这一向才停；已经碰上时，往外抽不受影响。长条不靠「离开缺口」来放开环。环留不留在盘上，只看环和环的连接。

银箍标出杆和环卡住的地方，不单独挡。

画面和规则是同一件事。圆环、胶囊棍、银卡扣的碰撞轮廓跟画出来的形状一致：画面重叠就挡住，画面之间有空隙就不算碰到。银卡扣套在棍上，棍可以穿过自己的卡扣。圆弧柄用来把另一只环嵌住：被嵌的环可以在柄里转，长着这只柄的环在还嵌着时不能把柄转出来。银箍必须落在杆和环真正卡住的地方。

关卡要有拆解先后。后一根杆的导轨被前面还在盘上的环挡住。只把后一根杆自己的开口转开不够，要等前面的零件离场。

## 2. 卡扣属于谁

每只卡扣只有一个主人。再加长条或圆环时，按主人挂上去，不写一对「又像环又像杆」的编号。

| 卡扣 | 主人 | 留住谁 | 怎么解开 |
|------|------|--------|----------|
| 银卡扣 | 一根长条 | 只留这根长条 | 整根杆身离开这只卡扣后，抬手这根长条才掉落。杆心过了卡扣、杆身还穿着时不掉 |
| 把手 | 一只圆环 | 主人，以及把手正嵌住的那只环 | 被嵌的环抬手时缺口对准这只把手 |
| 世界阻挡销 | 盘面 | 销还落在其实心里的那只环 | 这只环抬手时缺口盖住销。`block` 会挡住转动，`catch` 只留住环 |
| 银箍标记 | 一根长条 | 谁也不留 | 不删。主人离场时带走 |

环和环还通过把手连着时，两边都留在盘上。长条的银卡扣不参与这只连接。

## 3. 连接与障碍

| 种类 | 拖动 | 抬手 | 是否把零件留在盘上 |
|------|------|------|--------------------|
| 阻挡销 | 实心段顶住就停 | 缺口盖住则删这条连接 | 是。可删连接为 0 才离场 |
| 卡扣里的环 | 不挡这只环。它可以转进转出 | 抬手时缺口对准卡扣才解开 | 是。环和环还连着时两边都留着 |
| 长着卡扣的环 | 卡扣还嵌在对方实心里时转不动。对方缺口对准后，卡扣才能转出 | 不靠自己的缺口解开 | 是。这只连接同时留住两边。解开后，不再连着别的环才掉落 |
| 限位销 | `stopHalf > 0` 时顶住 | 不删 | 否。只限制角度，所属零件离场时带走它 |
| 银箍标记 | 不挡 | 不删 | 否。`stopHalf = 0` 的限位销，只标出杆和环的交叉，跟着所属的杆离场 |
| 长条自己的卡扣 | 不挡环的转动 | 杆滑出这只卡扣才解除 | 只留住这根长条。摘出来后长条掉落，环还彼此连着就留在盘上 |
| 闭合环 | 没有缺口，自己的抬手不删连接 | 只靠别的零件离场后的连锁 | 是，直到连接为 0 |

## 4. 主方法

环的轴是绕自身圆心的角度 θ，杆的轴是沿自己长边的位置 t。圆心和长边方向在这次拖动里不动。按住杆上的哪一点，杆就跟着这一点沿长边移动，不是把杆心拉到手指下面。

体积关（`volumes`）按画出来的形体走，不用轨道端点：

1. 环每次走一小步。这一步会从分开走进重叠，或者让已经重叠的地方更深，就停在这一步之前。重叠着时只能往分开的方向转。
2. 杆每次走一小步。只看正在前进的那一端。这一端要新进入环的实心，或在实心里变得更深，就停。杆身侧面已经贴着环时，沿长边抽出来不受影响。
3. 抬手才结算。环看缺口是否盖住别人的把手或世界销。杆有银卡扣时，看整根杆身是否还穿过这只卡扣；没有银卡扣的旧关卡才用松开窗口。
4. 银卡扣没了，这根长条掉落，不带走环。环不再连着别的环、也没有世界销留住时，这些环同一轮掉落。然后交给重力，没有地面，掉出画面下沿再删。

销钉关仍用区间：销在这根轴上占一段禁区，杆的 t 夹在 0 和 1 之间，抬手用松开窗口。

跟手只吃这一帧手指滑过的位移，被挡住的那截丢掉，不累加，松手后也不追手指。

圆环按切向弧长转。上一帧手指相对圆心是 `r`，这一帧位移是 `dp`，杠杆是 `max(|r|, 环带半径)`：`dθ = (rx·dpy − ry·dpx) / 杠杆²`。滑进孔里不会被放大，径向滑动不转。一帧里的直线按环带半径拆成小段再累加，不用 `atan2` 的最短角差。

长条只加手指沿长边的位移。挡住就停在接触前的那一步。

点选用射线，取最近的一个；没有命中再用环带或杆身的几何距离。按下只收设计画面内的点。拖动中用指针捕获，滑出画面仍跟踪。一次 `pointermove` 里的合并采样用 `getCoalescedEvents()` 按顺序吃完。

桌面预览会再缩放外层视口。指针先用画布的 `getBoundingClientRect` 换到设计坐标 390×844，再换到正交视口。不要只用 letterbox 的 `offsetX` / `offsetY`。

## 5. 辅助

主方法算不出禁区端点时才加辅助。夹紧和抬手结算不变。

| 情况 | 辅助 | 交回主方法的结果 |
|------|------|------------------|
| 销、卡扣、直杆 | 不需要 | — |
| 三角框、U 型管等不再是一个点的轮廓 | 临界角：绕定点把顶点与边求交，排序 | 禁区端点 |
| 个别形状临界角不划算 | 沿这根轴二分，找第一下接触 | 同一个端点 |

## 6. 不用

离散档位不作唯一模型。先转到目标再查重叠、动态合页、用接触生成互锁，都会改掉跟手或抬手时机。`DragControls` 的旋转绕相机轴，不绕环心。分离轴只回答是否重叠，不回答这根轴还能走多远。

物理引擎只在零件已经退出规则之后做掉落。还在规则里的零件不用动力学关节保持互锁。

## 7. 画面

规则在 XY 平面。正交相机从 +Z 看向原点，上方向是 +Y。角度 0 在 +X，逆时针。`mesh.rotation.z` 用同一个 θ。

当前画面是 `levelBasic`：蓝环、带衔接的绿环、带银卡扣的红棍。外形见 [PARTS.md](./PARTS.md)。环按 §4 绕自己的中心转，红胶囊棍沿长边滑动，银卡扣锁在画面上。松手按这一节结算。

解开之后才有重力。没有地面。圆环和长条往下掉，整件离开画面下沿后删除。还在规则里的零件不使用动力学关节，掉落物也不能把它们推开。

画面反馈只画在正在操作的那一只上，不写回规则角度或杆的位置。代码在 `src/game/feedback.ts`。

无效晃动的第一次幅度已定：圆环 3°，长条 3 个设计像素。来回 3 次，约 0.42 秒，后一次大约是前一次的六成。点击没有方向，直接播，幅度是按住的三分之二，零件还留在盘上才播。圆环这次还没带动规则姿态就被挡住时，按住停在第一次那一向上的 3°，继续拖不再采样，抬手后从这 3° 晃回规则角度。长条没有按住，挡住后立刻结束拖动并晃。已经带动过规则姿态的拖动继续跟手。

已经转过或滑过、这一下又被挡住时，零件发亮一次，并在接触点溅出 9 颗同色小圆片。接触点只取离挡住它的杆最近的那一块，不把环两侧的点平均到环心。粒子不透明，初始直径是 0.055 的 70%，按寿命缩小，重力为 16。同一次顶住不重复。圆环再转开约 0.08 弧度，或长条再滑过 0.03，下一次撞击才再亮。规则姿态仍停在接触前。杆和环的碰撞仍按画出来的环身，含缺口圆角。

## 8. 当前原型

关卡 `levelBasic`（`src/game/levels.ts`），名字「三件」：

1. 开局蓝环卡在绿环把手里。蓝环可以自由转进转出。松手时缺口正对把手，这只环和环的连接才解开；没对上就两边都还卡着。
2. 把手还嵌在蓝环实心里时，绿环转不动。蓝环缺口转到把手上之后，绿环才能把把手从缺口转出来。绿环自己的环身碰到红杆也会停。
3. 红杆斜着插在蓝环缺口里。杆从限制自己的卡扣里摘出来，松手后只有红杆掉落。两环还连着，留在盘上。
4. 环和环的连接解开之后，不再连着别的环的蓝环和绿环一起掉落。两个环的环身不互相挡。

银卡扣留在画面上的固定位置，不跟着杆滑。杆身还穿着它时，松手不掉。

关卡 `levelScreen`，名字「从上往下拆」。三环三杆，只能按这个顺序：

1. 红杆的银卡扣只属于红杆。抽出后松手，只有红杆掉落。蓝环由自己的世界销留住，缺口盖住这只销再松手，蓝环才掉。
2. 蓝环还在时，橙杆过不去。蓝环离场后，绿环开口转开，橙杆才能抽出。橙杆的卡扣只掉橙杆。绿环靠自己的销离场。
3. 绿环离场前紫杆过不去。橙环同样靠自己的销离场，紫杆靠自己的卡扣离场。

只转动圆环不会离场。卡扣写在环心，不在环带上，所以它把环留在盘上，但不把转动收成缺口那么窄。银箍是 `stopHalf = 0` 的限位销，坐标钉在杆上。
